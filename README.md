# GLC Admin · L'IA et l'automatisation au service des petites structures

Des outils simples et accessibles pour alléger l'administratif, la comptabilité et les RH des communes, PME et associations. Premier outil : le simulateur budget 2027 des communes genevoises.

| Outil | Pour qui | Lien |
|---|---|---|
| Simulateur budget 2027 | Les 45 communes genevoises | [docs/outils/simulateur-budget-2027](docs/outils/simulateur-budget-2027/) |

## Principes

- **Vos données restent sur le poste** : le simulateur genevois est un fichier HTML autonome qui ne se connecte à rien.
- **Gratuits, en échange de vos retours** : avis et critiques constructives sont les bienvenus à contact@glc-admin.com.

## Signaler une erreur

Ouvrez une « Issue » : https://github.com/GLC-administration/GLC-administration.github.io/issues/new . Précisez la commune, l'onglet concerné et ce qui vous semble inexact.

## Organisation des fichiers

Le site publié se trouve dans le dossier `docs/` (dossier de publication GitHub Pages).

```

docs/assets/logo-glc-admin.png                   logo
docs/outils/simulateur-budget-2027/              simulateur genevois, dossier de relecture, budget fictif
```
